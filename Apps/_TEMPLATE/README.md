# Bridge Project Documentation Template

Copy the contents of this folder into every new `Apps/<ProjectName>` repository during onboarding.

Required result:

```text
<ProjectName>/
├── START_HERE.md
└── docs/
    ├── HANDOFF.md
    ├── ARCHITECTURE.md
    ├── RUNBOOK.md
    ├── SECURITY.md
    └── ROADMAP.md
```

Replace every `<PLACEHOLDER>` before considering onboarding complete.

Rules:

- Keep these files in the project's **own Git repository**.
- Update `HANDOFF.md` and `ROADMAP.md` after substantial work.
- Never store raw secrets.
- Record implementation, deployment and E2E proof as separate states.
- Follow the parent Bridge `docs/PROJECT_STANDARD.md` contract.
