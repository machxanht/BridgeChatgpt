# User execution rules

- Finish the requested work before replying. Do not send progress updates unless a real blocker requires user action.
- Never generate or edit images unless the user explicitly asks for image generation or image editing.
- For small Bridge changes: inspect only exact files, edit, run proportional build/test, push GitHub, deploy Railway, then reply.
- Keep UI compact and functional. Remove redundant headers, dead icons, duplicate status cards, and unnecessary buttons.
- Do not claim PASS, deploy success, quota accuracy, or E2E success without actual evidence.
